# 关于COVID-19疫苗对于疫情的滞后性影响分析
项目背景
针对“高接种率伴随高确诊”这一公众认知误区，基于全球185个国家疫情面板数据，构建时间滞后相关性分析框架，系统揭示疫苗保护力在宏观数据中的真实作用周期。

项目流程与技术实现

· 通过 MySQL 搭建关系型数据库，利用 SQLAlchemy + pymysql 连接 Python（Jupyter Notebook），使用 Pandas 完成数据清洗与聚合，保留185个国家2020—2026年的累计确诊、每日新增及疫苗接种数据，并按经济水平划分为发达国家、发展中国家及特例组。  
· 引入人口静态数据，通过 Pandas 将绝对数值转化为 “每百万人” 核心指标，消除人口规模对分析结果的干扰。  
· 将“累计接种”差分还原为 “每日接种速度” ，构建0-60天与0-360天双滑动时间窗口，实现“今日接种”与“未来第N天新增病例”的精准对齐，为动态滞后分析奠定基础。  
· 计算 Pearson 相关系数，利用 Matplotlib 绘制相关性曲线，Plotly 生成热力图与动态地图，揭示滞后效应的时间演化规律。

数据分析与核心发现

· 热力图分析：大多数发展中国家“每日接种速度”与“未来病例”呈反常正相关，归因于“救火性接种”——即在疫情完全暴发后才启动大规模接种的被动应对模式，是反因果现象，而非疫苗无效。高医疗水平国家在滞后期呈现负相关，反向验证了疫苗在完善防疫体系下的真实保护效力。  
· 趋势分析：相关性曲线呈现稳定的 “四阶段周期”：  
  · 紧急响应期（0-30d）：正相关上升（疫情倒逼接种）；  
  · 免疫生效期（30-60d）：负相关回落（疫苗开始起效）；  
  · 保护衰减期（60-180d）：正相关达峰值（抗体衰退与加强针需求）；  
  · 平台回落期（180-360d）：持续负向下降（混合免疫积累）。  
      其中 30天拐点对应疫苗生效滞后性，180天峰值拐点对应中和抗体衰减周期，解释了疫情初期“疫苗无用论”的数据来源，同时为加强针策略提供了实证依据。

技术栈：Python / Pandas / NumPy / Matplotlib / Plotly / SQLAlchemy / pymysql / MySQL
